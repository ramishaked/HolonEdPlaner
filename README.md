# מפת המיומנויות והערכים (תוצר זמני)

ענף נפרד ועצמאי לחלוטין מאפליקציית HolonEdPlaner. אין בו קוד של האפליקציה, הוא לא מתמזג ל-main ולא מפעיל deploy ב-Vercel (ראו vercel.json).

- `index.html`: הכלי כולו בקובץ אחד. הנתונים מוטמעים כעותק, והדף מנסה למשוך נתונים עדכניים מהגיליון "מיומנויות וערכים - בסיס נתונים" (גרסה מפורסמת כ-CSV).
